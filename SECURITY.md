# Security Policy

Do not put logs, account information, secrets or private data in public Issues, Pull Requests or Actions artifacts.

If you find a security issue in this repository's patches or scripts, report it privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository, with reproduction steps, the affected commit and only the minimum necessary evidence. Do not disclose unpatched details publicly before a fix is agreed.

Security issues in MoltenVK itself belong to <https://github.com/KhronosGroup/MoltenVK>.
